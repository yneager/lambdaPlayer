# LAMBDA Player 0.3.0

- Meet Downloader+: download links, magnets and torrents without leaving the player.
- Drop a torrent or link into the app and choose where to save it before downloading.
- Enjoy smoother scrolling, cleaner episode scrollbars and optional 240 fps UI motion.
- Make LAMBDA yours with four color palettes, smooth scrolling and reduced motion settings.
- See updates clearly with a centered notice and a quick welcome after updating.

## Details

Downloader+ uses the download engine and client from DLmanager, with 128 torrent peers, a 32 MB disk cache, DHT, peer exchange and no download speed cap. Actual torrent speeds depend on available peers and network connectivity.

Encrypted peer connections and a larger receive buffer improve torrent performance on the tested connection. Encryption can be disabled in Settings for peers that do not support it.

UI motion defaults to 120 fps and can be set to 60, 120 or 240 fps, limited by the monitor. This setting does not change video playback or interpolation frame rates.

The download engine, required runtime files and third-party licenses are included in the Windows package.
