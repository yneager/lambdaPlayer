# LAMBDA Player 0.3.1

- Reduced motion now works without leaving the launch logo covering the app, including after restarting.
- Smoother scrolling and less background work while browsing and downloading.
- Downloads keep their progress cards steady instead of rebuilding them every second.
- Torrents can connect to more peers, including those without encryption, and avoid unnecessary connection resets.

## Details

Fixed the persisted reduced-motion launch overlay. The frame clock no longer rescans all CSS animations for inline style updates. Downloader+ updates existing cards in place, preserving focus and scroll position.

Torrent tuning now allows 256 peers, uses a 64 MB disk cache and continues seeking peers below 20 MB/s. Encrypted handshakes are preferred with fallback for legacy peers, instead of excluding those peers entirely. Restored torrents compare saved options before applying changes, avoiding unnecessary encryption-triggered restarts. The download engine also exits if its owning player process disappears.

Actual torrent speeds depend on the swarm and network; performance results are bounded tests rather than a guaranteed download rate.
