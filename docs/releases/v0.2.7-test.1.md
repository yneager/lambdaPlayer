Public testing prerelease for Windows 10/11 x64.

Download **LAMBDA-Player-Setup-0.2.7-test.1-x64.exe** and run it. The installer includes the app and its video, Qt, streaming and interpolation dependencies. No separate dependency installation is needed.

- Added a lambda app icon to the executable, installed shortcuts, taskbar, window, installer, and video file registration.
- Added **Your library → Add folder**: persistent movie/series cards, recursive episode discovery, natural ordering, and movie/series artwork lookup with offline poster caching. Use **Find artwork** to correct a match and **Rescan folder** to find newly added episodes.
- Local and online playback now save the episode and position every five seconds, on pause, on returning Home, when changing videos, and on normal exit. Online Continue Watching opens the saved episode's sources; choose an available stream to resume at the saved time.
- The installer offers LAMBDA in Windows **Open with** and **Default Apps**. Choose your preferred file types in Windows Settings after installation.
- Added experimental Fast RIFE interpolation with reusable low-resolution motion analysis, full-resolution synthesis, static-frame/cut shortcuts, adaptive output pacing, and improved presentation diagnostics. Performance depends on the GPU, video, and display refresh rate; stable 4K/240 fps is not guaranteed.

Please test folder imports, artwork matching, local/online resume, Explorer file opening, subtitles, fullscreen, scrolling, interpolation, and installation/uninstallation. Report issues with your GPU, Windows version, display refresh rate, and steps to reproduce.

Validation: 129 automated checks passed across nine test executables; packaged playback with a clean DLL search path, restart resume, and installer/uninstaller smoke tests passed. Online resume still needs testing with real installed stream add-ons on other PCs.
