# LAMBDA Player 0.3.2

- Choose which files to download from a torrent before it starts, including magnet links.
- Adjust subtitle size, position, background and timing to suit your video.
- Tune brightness, contrast, saturation and gamma, and customize your keyboard shortcuts.
- Enjoy a cleaner player without the middle pause/resume overlay, plus smoother browsing and tab changes.
- Build and Run now checks the required files and confirms the app opens, with logs if something goes wrong.

## Details

Torrent file selection shows file sizes and a selected total. Magnet links fetch their file list while the payload stays paused; cancelling removes the preview tasks.

Subtitle appearance and picture controls are saved. Subtitle timing resets for each video. Keyboard shortcuts are shared between Home and the player, support disabling and resetting, reject conflicting assignments, and stay out of the way while typing or adjusting sliders.

Offscreen animations pause, unchanged add-on cards are reused and startup animation work is reduced. The center playback overlay is removed from both the web UI and the native fallback.

The build helper compiles only the player during normal builds, checks runtime deployment, and verifies a player window opens. Use -Test to build and run native tests. Deployment diagnostics are in _local/qt-deploy.log; launch results are in _local/logs.
