Download **LAMBDA-Player-Setup-0.2.8-x64.exe** below and run it. This installer includes the complete Windows x64 app and its dependencies. The ZIP provides the portable app and the runtime used by in-app updates.

- Improved Universal interpolation by replacing coarse block matching with reusable neural motion. RIFE double/60 retain their motion settings. Motion analysis uses a smaller copy while synthesis samples the original full-resolution frames.
- Strengthened scene-cut detection for dark shots, color changes and shots with similar colors but different structure. Detected cuts hold the preceding original frame until the next source timestamp, avoiding interpolation between unrelated shots.
- Added an FPS show/hide button with separately labeled presentation, source and target rates.
- Added a configurable keyboard shortcut under Smoothness to toggle interpolation off/on and restore the last available mode. Shortcut preferences are saved.
- Added **Install default addons** beside Add-ons for Torrentio, Cinemeta and OpenSubtitles v3. It stays visible as **All installed**, preserves existing configurations, and installs only missing addons on retry.
- Centered the folder-library empty message and adjusted navigation for narrower windows.
- Improved GPU compatibility probing and visible explanations for unavailable interpolation modes.
- Added one-click downloads, verification, restart and rollback for future updates. Existing builds without the native updater need this installer once; later updates can run inside LAMBDA.

Includes the folder library, artwork lookup, local/online episode and time resume, Windows default-player registration, and lambda app icons introduced in the previous public test.

Validation: release build and Qt tests passed, default-addon UI regression checks passed, and synthetic 4K cuts passed at 48, 60 and 240 fps. A known-motion control still interpolates normally. These checks do not guarantee artifact-free interpolation for every film or stable 4K/240 fps on every GPU. Please report problematic scene switches and your GPU/display details.
